# NexarBank Advanced Database Portfolio

## Course
MIT 8103: Advanced Database Systems

## Case Study
NexarBank is a simulated Nigerian commercial bank.
This project demonstrates the design and implementation
of a relational banking database.

## Technology Stack
- PostgreSQL 18
- pgAdmin 4
- MongoDB
- GitHub

## Portfolio Activities
1. Database Design and Modelling
2. Query Processing and Optimisation
3. Transactions and Concurrency
4. NoSQL and Advanced Data Models
5. Distributed and Cloud Databases
